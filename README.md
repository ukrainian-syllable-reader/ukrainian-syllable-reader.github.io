# 🇺🇦 Ukrainian Syllable Reader (100-Words Drill)

Цей проєкт — інтерактивний веб-тренажер, створений для допомоги дітям (переважно першокласникам) у вивченні та закріпленні навичок читання українських слів по складах.

## 🚀 Live Demo

Спробуйте тренажер зараз:

[**https://ukrainian-syllable-reader.github.io/**](https://ukrainian-syllable-reader.github.io/)

## ✨ Особливості

* **100 Слів:** Фіксований набір слів для послідовного тренування.

* **Два Режими:** Режим **Склади** (для першого вивчення) та режим **Тренування** (лише цілі слова).

* **Адаптивний Інтерфейс:** Автоматичне розпізнавання сенсорного або клавіатурного вводу.

* **Підтримка Dark Mode:** Темна тема для комфортного читання та економії заряду.

* **Персоналізація:** Підбадьорливі повідомлення залежно від статі дитини.
